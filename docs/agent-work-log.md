# 공동 작업 기록

## 기록 원칙
Claude Code, Antigravity, Codex는 작업 전 이 파일과 Git 상태를 확인한다.
기존 변경을 덮어쓰지 않는다. 작업 후 아래 형식으로 추가한다.
도구 이름 / 날짜 / 변경 파일 / 변경 이유 / 테스트 결과 / 미완료 항목 / 커밋 및 배포 근거.
다른 도구의 작업은 추정으로 귀속하지 않는다. 비밀값·접속정보는 기록하지 않는다.

## 2026-10-10 — Antigravity 업데이트
근거: 사용자 확인 및 Git HEAD 8a7b1d9. 포털 분리, 관계 그래프와 조문 패널을 배포 화면에서 확인했다.
개별 커밋에 도구 서명이 없으므로 전체 커밋의 작성자를 단정하지 않는다.

## Claude Code — 과거 내역 미확인
확인 가능한 도구별 작업 기록이 아직 없다. Git 작성자 이름만으로 도구를 추정하지 않는다.

## 2026-10-11 — Codex
- main.tsx: 예제/서버 자료 출처 표시, 공식 원문 조회 연결, 요약을 제1조로 합성하는 경로 제거.
