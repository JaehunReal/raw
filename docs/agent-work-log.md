## 2026-10-14 — Codex: 자치법규 조문 번호 수정
- 원인: 자치법규 API의 6자리 식별자(앞 4자리 조, 뒤 2자리 가지)를 정수로 읽어 000100을 제100조로 표시했다. 사진의 대구광역시고등학교입학전형위원회규칙에서 재현했다.
- backend/rulecraft/article_numbers.py, law_sources.py, law_store.py: 수집 시 번호 해석과 기존 저장 자료의 조회·인용 번호를 수정했다. 운영 수집기 app/backend에도 같은 변경을 적용했다. 기존 로컬 변경은 유지했다.
- api/article-numbers.mjs, official.mjs: PostgreSQL 직접 조회와 Mac 중계 조회 모두 정정한다. 원본 XML, 본문, 버전, 해시, 기존 DB 레코드는 보존하며 응답 메타데이터에 이전 번호와 정정 방식을 남긴다.
- 전수 점검: 191,708개 저장 버전(자치법규 161,529, 행정규칙 24,188, 법령 5,991). 조번호 0인 전문을 제외한 자치법규 161,173개 버전의 2,249,805개 조문이 정정 대상이다. 기존 예비 집계는 전문 16개를 포함했으므로 이 수량이 최종이다.
- 별도 원문 예외: 번호·본문 불일치 후보 54건(제0조 전문 포함)은 exports/article-number-audit-20261014.json에 보존했다. 이 중 원문 자체의 가지번호 누락 등은 본문을 임의로 고치지 않았다.
- 검증: JS API·중계·번호 회귀 테스트 28개 통과. Python 수집기 테스트 web 47개/app 52개 및 번호 회귀 각 1개 통과. 제1조, 제1조의2, 실제 제100조, 전문, 일반 법령 비변경, 중복 정정 방지 검증.
- 커밋/배포: 이 항목을 포함한 커밋으로 GitHub main 및 Vercel 반영 후 실제 사진 대상 법규에서 재확인한다.

- 실제 조례 본문의 개정 필요성 판단은 이번 UI 분류 수정에 포함하지 않는다.
