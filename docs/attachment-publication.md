# 첨부 원본 우선 제공

2026-10-04 적용. 공식 법령 현황에 첨부 원본 목록을 추가한다. 로컬 본문 보완 작업에서 확인한 링크의 정적 공개본이며, 전체 첨부파일 수집 완료나 공개 PostgreSQL 연결 완료를 뜻하지 않는다. 화면에 목록 생성 시각과 범위를 표시한다.

## 표시 원칙

- 공식 law.go.kr HTTPS 원본 링크를 먼저 제공한다.
- 본문 파일임을 원본과 대조한 경우에만 “이 문서의 본문은 PDF로 제공됩니다”라고 표시한다.
- 별표·별지·서식은 붙임으로 표시한다. 기타 자료는 첨부 원본으로 표시하고 확인 중임을 알린다.
- 변환본은 원본 PDF의 수정본이 아닌 파생 자료다. 품질을 확인한 결과만 MD·JSON·이미지 묶음으로 제공한다.
- JSON의 내부 파일 경로는 상대 경로다. API 인증값·DB 주소·로컬 경로는 공개 목록에 포함하지 않는다.

## 변환 및 검토

로컬의 별도 Python 3.11 환경에서 Docling 2.133.0, EasyOCR 1.7.2를 사용한다. 한국어·영어 OCR, 표 구조, 페이지와 표 이미지, 원문 해시, 변환기 버전을 보존한다. 긴 문서는 10쪽씩 변환하며 변환 실패·일부 성공은 완전한 출력으로 공개하지 않는다. 작업은 한 번에 1건이다.

원문 SHA-256과 변환 산출물 manifest SHA-256에 묶인 검토 기록이 있어야 공개 목록에 다운로드 링크를 넣는다. 변환 성공 상태는 내용 정확성 검토 통과와 다르다. 각주 번호 연결은 별도 검증 대상이다.

첫 3건 검토 결과:

- **2026년도 부담금 분할납부 및 반환시 적용하는 이자율 고시**: 본문·날짜·수치·부칙을 원본 1쪽과 대조. 변환본 공개.
- **영산강Ⅳ지구 대단위농업개발사업 4-2공구 지형도면 고시**: 문장 및 조문 번호의 배치 오류. 원본 링크만 제공.
- **2026년도 조림비용 고시**: 표 금액·이미지는 확인했으나 제목·부칙 읽기 순서 오류. 원본 링크만 제공.

## 확인

- TypeScript 검사 및 프로덕션 빌드 통과.
- 기존 공식 조회 API 테스트 통과.
- 로컬 브라우저에서 첨부 목록, 검색, 본문 PDF 안내, 검증된 변환본 링크를 확인.
- 공개 데이터는 수집 당시 보존한 문서 버전에 연결되며 현행 법적 효력을 보증하지 않는다.
