# Laya 연결

공식 소스: https://github.com/NandhaKishorM/laya

`api/laya-ranking.mjs`는 Laya HTTP `/v1/systemone`에 한국어 다국어 모델의
noul 질문을 보내 현재 검색 페이지 상위 8개 법령 제목의 관련성을 재정렬한다.
조문 본문 검색이나 법적 타당성 검증이 아니다. 후보를 제거하지 않는다.
전체 제한시간 1.5초, 응답 크기/확률 검증, 보류·오류 시 원래 순서를 보존한다.
미설정 시 호출하지 않는다. 검색어와 공개 법령 제목·자료 유형만 전송한다.

## 활성화 전 필요 사항
1. 공식 Laya 배포 절차에 따라 지속 실행할 추론 서버를 구성한다.
2. 서버측 환경변수 RULECRAFT_LAYA_URL에 HTTPS `/v1/systemone` 주소를 설정한다.
   인증을 사용하는 서버이면 RULECRAFT_LAYA_TOKEN을 비밀 환경변수로 설정한다.
3. 한국어 법령 검색 평가셋으로 기본 검색 대비 관련성·p50/p95 전체 응답시간을 측정한다.
4. 평가 후 RULECRAFT_LAYA_ENABLED=true로 활성화한다.

현재 세션에서 추론 서버 주소와 설치된 Laya 런타임을 확인하지 못했다.
실모델 품질·성능은 미검증이며 기본 검색을 유지한다. 모의 응답 테스트는 실모델 평가를 대체하지 않는다.
