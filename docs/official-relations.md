# 공식 법령 관계

기존 공개 그래프는 정적 예제 데이터만 사용했고, 공식 조문 투영 함수는 단일 노드만 반환했다. 공식 법령 검색·본문 API에는 관계 조회가 없었다.

이제 Mac PostgreSQL에 버전별 명시적 법령명 인용을 색인하고 `/api/official/graph`가 인용과 역인용을 반환한다. 「법령명」 또는 『법령명』을 저장된 정규화 법령명과 대조하며, 둘 이상의 법령 식별자에 해당하면 자동 연결하지 않는다. 증거 문장, 출처 버전, 원문 SHA-256을 보존한다.

시행령·시행규칙의 이름과 원문의 해당 법 인용이 함께 일치할 때만 `implementation_basis`를 사용한다. 그 외는 `citation`이다. 행정규칙·조례의 단순 인용을 상위법·위임으로 판정하지 않는다. 관계를 찾지 못한 경우에도 관계 없음으로 단정하지 않는다. 약칭·이 법·같은 법·따옴표 없는 인용·직접적인 위임 조문 판정은 아직 포함하지 않는다.

화면의 관계 그래프 메뉴와 공식 원문 상세에서 실제 관계를 조회하고 연결된 법령을 선택해 탐색할 수 있다. MCP `official_graph`도 같은 API를 사용한다. 기존 `query_markdown_graph`는 기존의 조문 단위 투영 동작을 유지한다.

최대 60개 증거 행을 검사하고 중복 법령 노드를 합친다. 시행 근거와 선택 법령의 인용을 우선한다. 대상의 최신 저장 버전을 보여줄 수 있으므로 연결된 버전들의 동시 효력은 별도 확인이 필요하다. 본문 변경 후 Mac에서 `build_official_relations.py`를 다시 실행한다. 새 색인은 트랜잭션 완료 후 조회되며 기존 문서·원본은 변경하지 않는다.
