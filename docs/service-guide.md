# 공무원용 서비스 소개와 MCP 안내

## 목적과 화면 구성

처음 방문한 규정 담당자가 서비스의 용도, 시작할 메뉴, MCP 사용 위치를 이해하도록 공개 첫 화면을 구성했다.

- 첫 화면: 서비스 목적 → 법령·기관 규정·서식 연결 개념도 → 찾기·연결 확인·검토 준비 → 웹/MCP 사용 방법 → 자료 상태.
- 각 업무 단계의 버튼은 기존 규정 예제·관계도·문서 예제로 이동한다. 공식 법령 조회 연결과 상태 표시는 유지한다.
- MCP 사용 안내: 질문 → 도구 사용 → 담당자 검토 흐름, 연결 요청 순서, 세 가지 요청문과 복사 버튼, 결과 확인 항목.
- 설정 명령과 과거 기술 검증 기록은 펼쳐 볼 수 있다. 공개 웹에서 MCP가 실행되거나 AI 모델이 연결됐다고 표시하지 않는다.
- 실제 MCP 실행 화면에도 동일한 안내를 제공한다. 공식 법령과 합성 예제의 구분은 유지한다.

## 확인 결과 (2026-10-03)

- TypeScript 검사와 공개 프런트엔드 프로덕션 빌드 통과.
- 인증 게이트웨이 테스트 17개, 공식 조회 게이트웨이 테스트 23개 통과.
- 로컬 브라우저에서 첫 화면→MCP 안내 이동, 업무 예제 선택, 요청문 복사 성공 메시지, 관계도 이동, 담당자 설정 펼치기를 확인했다.
- 폭 390·768·1440px에서 안내 페이지의 문서 가로 넘침이 없음을 확인했다.
- 기존 공개 화면 브라우저 회귀 테스트의 메뉴명과 MCP 안내 검사를 새 화면에 맞췄다. 전체 브라우저 회귀 스크립트는 이 세션에서 실행하지 않았으며 위 항목은 브라우저 직접 검사 결과다.
- 로컬 Vite 단독 실행은 공식 DB API를 제공하지 않으므로 ‘저장소 응답 확인 필요’로 표시됐다. 실제 원문 건수나 DB 연결 성공을 이 검사로 주장하지 않는다.
